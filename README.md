# WindTunnel 🌪️

Stress-test lab and adversarial simulation engine for Meteora Dynamic Bonding Curve (DBC) token launches.

## Overview
WindTunnel simulates DBC token launches against real-world adversarial trading strategies (snipers, bundlers, momentum buyers, whales, and post-graduation arbitrageurs) using Meteora's mathematical formulas and SDK.

## Structure
- `core/`: Simulation engine, DBC curve modeling, fee schedulers, and agent simulator (TypeScript, Node).
- `docs/`: Research notes, SDK reconnaissance, and architecture specs.
- `web/`: User interface and dashboard (Next.js - upcoming phase).
